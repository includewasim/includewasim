### 👋 About me

I build things end-to-end — from full-stack web apps to full infrastructure platforms. Currently deep in **platform engineering**: self-service catalogs, GitOps delivery, and AI-assisted guardrails that don't just log risk, they can actually block it.

- 🔭 Currently building **[self-service-infra-platform](https://github.com/includewasim/self-service-infra-platform)** — Backstage + Terraform + ArgoCD + an AI review layer that blocks risky infra changes before they're applied
- 🌱 Currently deepening **AWS networking internals, Kubernetes RBAC/scheduling, and Terraform state management**
- 💬 Ask me about **Kubernetes, Terraform, GitOps, or why your VPC peering isn't working** (I wrote a tool for that — [vpc-validator](https://github.com/includewasim/vpc-validator))
- 📍 Based in India
